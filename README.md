# 통조림

통조림은 작가의 지시에 따라 소설 원고를 한 장면 정도 이어 쓰는 한국어 집필 도구입니다. 내 컴퓨터에서 서버를 실행하고 데스크톱 브라우저로 사용합니다. AI 생성에는 OpenRouter를 사용합니다.

## 시작하기

Node.js 22 이상이 필요합니다. 저장소 루트에서 바로 실행할 수 있으며 별도의 패키지 설치나 빌드가 필요 없습니다.

1. AI 기능을 사용하려면 `package.json`과 같은 폴더에 `.env` 파일을 만들고 OpenRouter API 키를 설정합니다.

   ```dotenv
   OPENROUTER_API_KEY=여기에_발급받은_키
   ```

   서버 환경 변수로도 설정할 수 있습니다. 기존 변수 이름인 `OPENROUTER_API`도 지원합니다. API 키는 서버에서만 읽습니다.

2. 저장소 루트에서 서버를 실행합니다.

   ```sh
   npm start
   ```

   Windows PowerShell에서 `npm.ps1` 실행이 차단되면 `npm.cmd start`를 사용합니다.

3. 데스크톱 브라우저에서 [집필실](http://127.0.0.1:4173)이나 [모델 설정](http://127.0.0.1:4173/settings)을 엽니다.

서버를 종료하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다. 기본 포트가 이미 사용 중이면 `.env`에 `PORT=4174`를 추가하고 서버를 다시 실행한 뒤 해당 포트로 접속합니다.

### OpenRouter 사용량과 크레딧

**설정 → OpenRouter 사용량**에서 집필용 키의 사용액과 남은 지출 한도를 확인할 수 있습니다. 계정 크레딧 잔액도 보려면 [OpenRouter 관리 키 발급 화면](https://openrouter.ai/settings/management-keys)에서 발급한 관리 키를 `.env`에 추가하고 서버를 다시 시작합니다.

```dotenv
OPENROUTER_MANAGE=여기에_발급받은_관리_키
```

## 집필하기

1. **설정**에서 **이어쓰기 모델**을 선택합니다.
2. 집필실에서 원고를 입력하고 **작가의 노트**에 다음 장면의 지시를 적은 뒤 **이어서 쓰기**를 누릅니다.
3. 초안을 읽고 **원고에 추가**를 누릅니다.

선택한 문단을 퇴고하거나, 작품 메모와 로어북 카드 작성에 AI 도우미를 사용할 수 있습니다. **요청 미리보기**에서 이어쓰기에 들어갈 참고 자료를 확인할 수 있습니다. **의미 검색**을 켜면 검색어와 과거 원고 문단이 OpenRouter로 전송되며 임베딩 비용이 발생할 수 있습니다.

## 저장과 백업

원고와 작품 설정은 사용 중인 브라우저에 저장됩니다. 브라우저, 접속 호스트 또는 포트가 바뀌면 별도 저장소가 열립니다. 작업 환경을 옮기려면 집필실의 **작품 파일 → JSON 백업**으로 저장하고, 새 환경에서 **작품 파일 → 새 작품으로 복원**을 선택합니다. 원고만 필요하면 **TXT 내보내기**를 사용합니다.

## 테스트

```sh
npm test
```

화면이나 생성 흐름을 확인하려면 `npm run qa:server`를 실행한 뒤 [QA 집필실](http://127.0.0.1:4184)을 엽니다. 설정에서 이어쓰기 모델로 `qa/write`를 선택하면 실제 API 키 없이 샘플 원고로 이어쓰기를 확인할 수 있습니다. 검색을 점검하려면 모의 서버가 실행 중인 상태에서 별도 터미널로 `npm run qa:retrieval -- 4184`를 실행합니다.

개발 시 저장소의 [작업 지침](AGENTS.md)을 참고하세요.
